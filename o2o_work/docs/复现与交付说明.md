## 从原始数据重建阶段0—4

1. 从来源页面自行获取有权使用的数据，确认许可。将config/input_lock.json列出的四个文件放到仓库根目录的o2o/。严格要求文件名、字节大小和SHA256一致，其他版本会拒绝运行。
2. 使用Python 3.11创建o2o_work/.venv，安装o2o_work/requirements-stage4.lock.txt。
3. 执行outputs/dataset_review_20261014/数据核验.ipynb，真实核验输入指纹。profile.json的行数来自之前的本地核验，不代表本次重新全量计数。
4. 创建o2o_work/data和o2o_work/qa目录。依次执行./o2o_work/run.sh stage0、stage1、stage2、stage3。入口会写本克隆目录中的派生数据与状态。
5. stage4还需安装Tableau，参考阶段4看板配置与复现及scripts/stage4_dependencies.py。默认只生成包，不操作GUI；数据准备通过仍为PARTIAL，真实原生交互需另行验收。

```sh
python3.11 -m venv o2o_work/.venv
o2o_work/.venv/bin/python -m pip install -r o2o_work/requirements-stage4.lock.txt
mkdir -p o2o_work/data o2o_work/qa
chmod +x o2o_work/run.sh
# 先执行上面的输入指纹Notebook，再运行阶段入口
./o2o_work/run.sh stage0
./o2o_work/run.sh stage1
./o2o_work/run.sh stage2
./o2o_work/run.sh stage3
```

stage5/stage6是原工作目录的文档/历史修复凭据登记工具，不是全新克隆的通用复现入口；相关原始历史凭据未发布。不要在克隆后直接执行stage5/stage6并期待继承本地PASS。
