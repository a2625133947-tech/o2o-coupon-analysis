## 总体基准与阅读口径

领券窗口2016-01-01至06-15，消费观察截至06-30；15日核销含第0日与第15日，领券全部成熟。15日核销记录 **64,395 / 1,053,282 = 6.1137%**；至少核销一条的用户 **40,075 / 510,698 = 7.8471%**。记录率和用户占比不可替代，跨组独立用户不可直接相加。普通消费701,602条不进入领券分母。

共同层比较按已观察维度精确分组，两侧每层各至少30条；共同权重为两侧领券量之和。标准化率为 `SUM(w×层内核销率)/SUM(w)`，其分子是带权等效核销量，**不是实际观察核销条数**。标准化不等于随机化、完整去混杂或显著性检验。

## F1 同门槛券方案的排序反转，但共同覆盖很小

**问题：** 更高名义优惠的券方案是否有更高核销率？总体排名不足以回答效果问题。

**观察：** 20:5全体为 **11,796/91,013=12.9608%**，20:1为 **6,941/51,705=13.4242%**。100:30为 **683/38,196=1.7881%**，100:10为 **3,904/182,554=2.1385%**。

**可比范围与覆盖：** 同月份、商家、距离及相同门槛，20元组保留11层：真实核销/领券为 **313/733** 与 **396/2,346**，共同覆盖 **733/91,013=0.8054%** 与 **2,346/51,705=4.5373%**；标准化率 **42.3229%/18.5721%**，标准分母3,079，等效分子1,303.121568/571.835799。100元组保留7层：真实 **60/637** 与 **19/4,245**，覆盖 **637/38,196=1.6677%** 与 **4,245/182,554=2.3253%**；标准化 **16.2634%/0.3956%**，标准分母4,882，等效分子793.981376/19.312286。两对方向都反转。

**解释假说：** 券方案的商家、日期、用户构成不同；严格共同层本身又筛出特殊子样本。

**建议：** 先核实可比覆盖，再在同商家/日期/门槛及可比用户中小规模随机测试券方案，补充成本和触达。

**限制与待验证：** 共同覆盖均低于5%，无法外推全部券方案；没有控制用户选择或商品，不证明优惠力度效果，也不能把总体排序与反转任何一方当增量结论。

**来源与行筛选：** [券方案表](../results/stage2/runs/20261015T154046130013/coupon_scheme_metrics.csv)（discount_rate IN ('20:5','20:1','100:30','100:10')）；[共同汇总](../results/stage2/runs/20261015T154046130013/comparison_summary.csv)（comparison_id IN ('20_5_vs_20_1','100_30_vs_100_10') AND support_rule='common_min30_each'）；[逐层](../results/stage2/runs/20261015T154046130013/comparison_strata.csv)（同comparison_id且adequate_common_support=true）；[券SQL](../sql/03_coupon.sql)（coupon_scheme_metrics）；[可比SQL](../sql/07_comparable_review.sql)（comparison_summary）。

## F2 距离编码差异在共同范围内保留，差距缩小

**问题：** 编码0与10的差异是否主要来自月份、商家、券方案构成？

**观察：** 编码0为 **40,281/348,179=11.5690%**，编码10为 **2,086/172,749=1.2075%**；未知距离单列，**7,335/106,003=6.9196%**。

**可比范围与覆盖：** 同月份、商家、精确券方案保留200层，真实核销/领券 **16,544/222,961** 对 **707/155,141**；覆盖 **222,961/348,179=64.0363%** 与 **155,141/172,749=89.8072%**。标准化率 **5.6732%/1.5884%**；标准分母378,102，等效分子21,450.293689/6,005.818843。差距从全体10.3615个百分点缩至4.0847个百分点。

**解释假说：** 出行便利性可能相关，用户偏好、商品和活动选择也可能解释差异。

**建议：** 活动复盘加入距离构成，对不同编码组的触达方案分别设置对照验证。

**限制与待验证：** 编码不能直接解释成精确公里；剩余差异不证明距离导致核销变化，不推算缩短距离的提升。待补用户、商品和实际曝光。

**来源与行筛选：** [距离表](../results/stage2/runs/20261015T154046130013/distance_metrics.csv)（distance_group IN ('0','10','unknown')）；[共同汇总](../results/stage2/runs/20261015T154046130013/comparison_summary.csv)（comparison_id='distance0_vs10' AND support_rule='common_min30_each'）；[距离SQL](../sql/04_distance.sql)（distance_metrics）；[可比SQL](../sql/07_comparable_review.sql)（comparison_summary）。

## F3 最大领券量商家3381适合诊断，参照覆盖限制解释

**问题：** 低率且规模大的商家，是否可以据此判为运营差？

**观察：** 3381为 **1,553/122,834=1.2643%**；其他商家合计 **62,842/930,448=6.7540%**。全部5,599个商家领券中位数10条，其中5,140个不足100条，不宜强排行。100条仅是提示阈值，达到也不保证稳定。

**可比范围与覆盖：** 同月份、精确券方案、距离保留54层。3381真实 **1,281/93,512**，其他商家 **480/26,999**；覆盖 **93,512/122,834=76.1288%** 对 **26,999/930,448=2.9017%**。标准化 **1.5199%/2.4501%**，标准分母120,511，等效分子1,831.636264/2,952.618583；差距从全体5.4896个百分点降至0.9302个百分点。

**解释假说：** 已观察结构解释部分差距，剩余可能涉及用户、商品、门店属性和活动安排。

**建议：** 优先审查3381的券门槛、使用障碍、商品及触达曝光，再决定小规模试验。

**限制与待验证：** 参照组仅覆盖其他商家2.90%，不能代表全部商家；没有商品/成本/曝光，不判定运营能力、利润或可实现提升。

**来源与行筛选：** [商家表](../results/stage2/runs/20261015T154046130013/merchant_metrics.csv)（merchant_id='3381'；其他商家按其余记录汇总）；[商家分布](../results/stage2/runs/20261015T154046130013/merchant_distribution.csv)（唯一行）；[共同汇总](../results/stage2/runs/20261015T154046130013/comparison_summary.csv)（comparison_id='largest_merchant_vs_peers' AND support_rule='common_min30_each'）；[商家SQL](../sql/05_merchant.sql)（merchant_metrics/merchant_distribution）；[可比SQL](../sql/07_comparable_review.sql)（comparison_summary）。

## F4 第7日占成功者73.41%，仅占全部领券4.49%

**问题：** 自然核销何时出现，如何为后续提醒实验选择候选时点？

**观察：** 第7日累计47,274条，**47,274/64,395=73.4125%** 是最终成功者内占比，**47,274/1,053,282=4.4883%** 才是全体领券累计率。第15日 **64,395/1,053,282=6.1137%**；成功者等待中位数5天、均值5.1422天。

**可比范围与覆盖：** 同一成熟领券群体1,053,282/1,053,282，覆盖100%；累计到第7日与第15日用同一分母。成功者等待分布只覆盖64,395条成功记录。

**解释假说：** 自然需求、活动时点、券有效期可能影响等待分布。

**建议：** 将首周若干时点列为提醒实验候选，保留不提醒对照并采集曝光、退订、打扰和成本。

**限制与待验证：** 没有提醒记录或随机对照，不存在已验证最优提醒日，也没有提醒提升测算；成功者分布不能替代全体领券概率。

**来源与行筛选：** [累计表](../results/stage2/runs/20261015T154046130013/redemption_lag.csv)（lag_day IN (7,15)）；[等待摘要](../results/stage2/runs/20261015T154046130013/redemption_lag_summary.csv)（唯一行）；[核销时间SQL](../sql/06_redemption_lag.sql)（redemption_lag/redemption_lag_summary）。

## F5 历史群体区分后续行为，不等于营销增量排序

**问题：** 仅用5月1日前可见历史分层，能观察到哪些5月后续差异？

**观察：** 近期高频：**7,855/37,941=20.7032%**，用户核销 **4,342/17,032=25.4932%**，用户均权率16.6411%。近期低频：**2,578/24,145=10.6772%**，用户核销 **1,908/14,753=12.9330%**，用户均权8.7179%。历史多领零核销后续仍 **915/10,913=8.3845%**，用户 **681/6,738=10.1069%**。未知历史 **6,046/84,093=7.1897%**，用户 **4,660/67,928=6.8602%**。六组合计 **21,580/215,348=10.0210%**；核销用户 **14,860/148,439=10.0108%**。

**可比范围与覆盖：** 历史期[2016-01-01,2016-05-01)，评价为5月领券、消费观察截至6月15日。高频5月领券覆盖 **17,032/34,588=49.2425%**，低频 **14,753/40,148=36.7465%**，历史多领零核销 **6,738/33,053=20.3854%**；这是已观察分层内领券覆盖，非结构控制后的共同覆盖。未知历史 **67,928/67,928=100%** 是历史与5月用户并集构造结果；没有5月1日前历史，也不能倒推当时可触达。尚未完成分层间券/商家/距离共同支持及覆盖率分析。

**解释假说：** 历史活跃性可能与后续自然需求相关；群体的券、商家、距离和活动选择也可能不同。

**建议：** 高频优先验证自然核销之外的增量及过度补贴风险；多领零核销先诊断障碍再试验；未知历史首次可见后补足覆盖信息。

**限制与待验证：** 未知历史不是平台新用户；历史零核销不是永不核销；非近期不是平台流失。多领零核销规则优先于RF，高频/低频不是全部近期用户。未控制后续构成，没有收入、成本和曝光，不按营销价值或ROI排序。

**来源与行筛选：** [分层评价](../results/stage3/runs/20261015T154103504261/segment_evaluation.csv)（六个segment_id全行）；[用户均权](../results/stage3/runs/20261015T154103504261/segment_user_evaluation.csv)（六组全行）；[历史覆盖](../results/stage3/runs/20261015T154103504261/segment_coverage.csv)（六组全行）；[优先规则](../results/stage3/runs/20261015T154103504261/rule_catalog.csv)（按priority排序）；[历史SQL](../sql/08_user_features_asof.sql)（user_features_asof）；[分层SQL](../sql/09_user_segments.sql)（user_segments）；[评价SQL](../sql/10_user_segment_evaluation.sql)（segment_evaluation）。

优先顺序按“能否取得合格名单、成本和对照证据”决定，不按自然核销率从高到低直接发券。以下是可落地的验证设计，不是已上线方案或预期提升承诺。
